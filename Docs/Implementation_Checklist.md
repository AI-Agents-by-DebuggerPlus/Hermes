- [x] Создать WPF приложение на .NET 8

- [x] Подключить глобальные стили и темную тему

## 2) UI (Command Center)
- [x] Реализовать 3 панели: `Project Manager`, `Chat`, `Terminal Output`
- [x] Добавить быстрые действия: `status`, `gateway run`, `gateway reset-webhook`, `analyze code`
- [x] Добавить отдельное окно логирования

## 3) Hermes Integration
- [x] Отправка сообщений в Hermes через `wsl.exe` + `hermes chat -z`
- [x] Выполнение quick actions через `hermes <command>`
- [x] Потоковый вывод stdout/stderr в терминальную панель
- [x] Отправка сообщения по `Enter`, перенос строки по `Shift+Enter`

## 4) Хранение данных

- [x] Загрузка истории при выборе проекта

## 5) Логирование
- [x] Дублировать runtime-логи в UI-окно логов
- [x] Дублировать runtime-логи в файл
- [x] Хранить логи в `D:\Programming\AI_Agents\Hermes\Docs\Logs`
- [x] Авто-очистка старых логов: оставлять только 3 последних файла

## 6) Что нужно для рабочего подключения чата к Hermes
- [ ] На Windows должен быть установлен и рабочий `WSL`
- [ ] В WSL должен быть установлен Hermes CLI (`hermes` в PATH)
- [ ] Должна существовать среда `~/hermes-agent/venv` с зависимостями
- [ ] Команда `source ~/hermes-agent/venv/bin/activate && hermes status` должна выполняться без ошибок
- [ ] Для выбранного проекта должен быть корректный путь на Windows (конвертируется в `/mnt/...`)
