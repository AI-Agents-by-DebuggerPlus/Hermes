# Озвучка EN/RU в Hermes.EnglishLearning

**Рекомендация:** озвучку делать **на стороне WPF**, не гонять аудио через Supabase.

---

## Сравнение способов

| Способ | Плюсы | Минусы | Win7 |
|--------|-------|--------|------|
| **1. Windows SAPI (`System.Speech`)** — *уже в приложении* | Без сети, бесплатно, просто | Качество голосов среднее; нужны установленные голоса EN/RU | Да |
| **2. Windows 10/11 OneCore / Neural voices** | Лучше качество | На Win7 нет; API сложнее | Нет |
| **3. Offline eSpeak / RHVoice** | Контроль, офлайн | Отдельный рантайм, интеграция | Да |
| **4. Облачный TTS (Azure / Google / OpenAI)** | Высокое качество | Нужен ключ, сеть, задержка; кэш файлов локально | Да (HTTP) |
| **5. Готовые MP3 от агента через Storage** | Студийное качество | Трафик, квоты, сложность; против вашей цели «не слать аудио» | Да |

**Итог для старта:** оставить **SAPI** (кнопка «Озвучить» / клавиша `S`).  
Позже — опциональный облачный TTS с **локальным кэшем** WAV по хешу фразы.

---

## Как работает сейчас

- `LocalTtsService` — `System.Speech.Synthesis`.
- Озвучивает все карточки текущего экрана: EN (`en-US`) → RU (`ru-RU`).
- Аудиофайлы **не** передаются через Supabase.

### Требования к ОС

- Голос English (United States) и Russian — в «Параметры речи» / Language packs.
- Если голоса нет, SAPI говорит дефолтным голосом (акцент может быть неверным).

---

## Возможное развитие

1. Переключатель «только EN» / «только RU» / «EN затем RU».
2. Кэш: `%LocalAppData%\HermesEnglishLearning\tts\{hash}.wav`.
3. Настройка: SAPI vs Azure Speech (ключ в settings.json).
4. Hermes в MD может добавить опциональные поля `ipa:` / `hint:` — без аудио.
