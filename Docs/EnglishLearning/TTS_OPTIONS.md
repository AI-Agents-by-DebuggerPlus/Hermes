# Озвучка EN/RU в Hermes.EnglishLearning

**Рекомендация:** озвучку делать **на стороне WPF**, не гонять аудио через Supabase.

---

## Порядок озвучки одной карточки

1. Английский  
2. Русский  
3. Английский  
4. Английский  

Символ `/` не произносится — пауза между альтернативами.

**Play/Pause гарнитуры:**
- идёт озвучка → пауза / продолжить;
- экран уже дочитан → **следующий экран**.

Глобальный `RegisterHotKey(VK_MEDIA_PLAY_PAUSE)` — чтобы кнопка работала **до** первого «Озвучить».

---

## Какие голоса сейчас

1. **Azure Neural + кэш** (рекомендуется): голоса в настройках, блок «Azure Speech»; кнопка **Кэш TTS** скачивает весь урок в `tts-cache\` без прослушивания. В логе: `TTS cache HIT` / `MISS` / `WRITE`.
2. **Windows SAPI** (`System.Speech`): отдельный блок в настройках.

---

## Облачный TTS с локальным кэшем (подробнее)

Идея: не слать аудио через Supabase, а на ПК:

1. Хеш фразы + язык + голос → имя файла, напр.  
   `%EXE%\tts-cache\en_{sha1}.wav`
2. Если файл есть — играть локально (MediaPlayer / NAudio).
3. Если нет — один HTTP-запрос к Azure Speech / Google Cloud TTS / OpenAI Audio → сохранить WAV/MP3 в кэш → играть.

| Плюсы | Минусы |
|-------|--------|
| Качество студийных голосов | Нужен API-ключ и интернет при **первом** проигрывании |
| Повтор фраз мгновенный и офлайн | Кэш занимает место (для одной песни — мелочи) |
| Не нагружает Supabase | На Win7 нужен TLS 1.2 (обычно уже есть) |

Практичный сценарий «подготовка на Win10 → флешка → Win7»:

1. На Win10 один раз прогнать весь урок с облачным TTS (кэш заполнится).
2. Скопировать папку приложения **вместе с `tts-cache\`** на флешку.
3. На Win7 при отсутствии сети кэш уже есть — озвучка работает офлайн.

Ключ API при этом можно не возить на удалённый ПК, если кэш полный.

## Можно ли перенести голоса Win10 на Win7?

### Короткий ответ

**Штатные голоса Windows 10/11 (OneCore / Neural) на Win7 обычно не переносятся.**  
Это другие движки и пакеты; простое копирование с флешки не ставит их как SAPI5 на Win7.

### Что реально работает на Win7

| Вариант | Перенос на флешке |
|---------|-------------------|
| **SAPI5 + Microsoft Speech Platform Runtime** + Language Packs (MSSpeech) | Да: установщики `.msi` на флешке → поставить на Win7 |
| **RHVoice** (SAPI5) | Да: инсталлятор + голоса |
| **Облачный TTS + папка `tts-cache`** | Да: копируете кэш WAV вместе с приложением |
| Голоса из «Параметры → Речь» Win10 | **Нет** надёжного переноса на Win7 |

### Рекомендуемая схема для удалённого Win7

1. **Основное:** SAPI / Speech Platform / RHVoice, установленные на месте.  
2. **Качество:** заранее сгенерировать `tts-cache` на Win10 и скопировать с приложением.  
3. Не рассчитывать на копирование системных папок `Speech_OneCore` с Win10.

---

## Как добавить SAPI-голоса на Win7

1. Microsoft Speech Platform Runtime (x86/x64)  
2. MSSpeech Language Pack — English и Russian  
3. Перезапуск приложения → вкладка **Голоса**

---

## Чего не делать

- Не класть base64-аудио в `messages.content`.  
- Не ждать, что «пакет голосов Win10» просто заработает на Win7 без отдельного SAPI/Speech Platform.
